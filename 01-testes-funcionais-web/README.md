# 🧪 Projeto 01 — Testes Funcionais Web

## 📌 Sobre o projeto

Projeto prático de Quality Assurance voltado à aplicação de testes manuais e funcionais em uma aplicação Web.

O projeto será desenvolvido progressivamente, contemplando desde o planejamento dos testes até a execução, documentação de evidências, reporte de defeitos e retestes.

## 🎯 Objetivos

- Analisar os requisitos e funcionalidades da aplicação
- Elaborar cenários de teste
- Elaborar casos de teste
- Executar testes manuais e funcionais
- Documentar evidências
- Identificar e reportar bugs
- Realizar retestes
- Elaborar relatório final da execução

## 🛠️ Tipos de testes

- Testes manuais
- Testes funcionais
- Testes positivos e negativos
- Testes exploratórios
